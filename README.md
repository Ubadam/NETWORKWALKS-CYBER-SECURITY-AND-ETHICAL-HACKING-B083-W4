I’m excited to share the completion of my Week 4 cybersecurity project during my internship at NetworkWalks.

This week, I worked on a black-box penetration testing assessment of the Mediroza General Hospital web application, within an authorized educational lab environment.

Throughout the project, I worked through several stages:

* M1 Initial Access
• Web application reconnaissance and enumeration
• Analysis of exposed resources
• Authentication analysis
• Identification and retrieval of authorized test documents

* M2 Data Extraction
• Hash extraction from protected PDF documents
• Password recovery using appropriate techniques
• Decryption and analysis of the recovered documents

* M3 Critical Data Exposure
• Investigation of historical and exposed resources
• Identification of sensitive organizational information
• Analysis of document metadata
• Identification of employee salary and shareholder information within the authorized lab scope

* M4 Penetration Testing Report
• Executive summary
• Scope and methodology
• Findings and proof of exploitation
• Risk classification
• Security impact analysis
• Recommendations and remediation strategies

This project allowed me to strengthen my practical skills in:

🛡️ Web Application Security
# Reconnaissance & Enumeration
🔐 Authentication & Password Security
📄 Sensitive Data Exposure Analysis
# Penetration Testing
📊 Risk Assessment & Security Reporting

More importantly, this experience reinforced the importance of identifying security weaknesses not only at the technical level, but also from the perspective of data confidentiality, access control, and organizational security.

And endless appreciations  to sir Waqas Karim (CCIE) and NETWORKWALKS team and everyone who contributed to this learning experience. 🙏
